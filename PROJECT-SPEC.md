# Project Specification: Daymark Todo App

## Goal

Build a beginner-friendly, responsive todo list that lets a person organize everyday tasks without a framework or account.

## Main features

- Add a task with a short text description.
- Mark tasks as active or completed.
- Delete tasks from the list.
- Filter tasks by all, active, or completed status.
- Display the total task count and number of active tasks.
- Save task data in browser localStorage so it persists across refreshes.

## Expected functionality

- Submitting a non-empty task adds it to the list and clears the input.
- Changing a task's completion status updates the list and counts.
- Selecting a filter displays only tasks that match it.
- Deleting a task removes it from the list and saved data.
- Changes remain available after reloading the page in the same browser.
- The interface remains usable on desktop and mobile screen sizes.
